肝細胞癌與末期肝病綜合計算機 (HCC & Liver Disease Calc)

這是一個專為肝膽腸胃科醫師與醫療人員設計的單頁式互動網頁應用程式 (Single-Page Application, PWA)。本工具整合了臨床上最常用的肝功能預後評估分數以及肝細胞癌 (HCC) 國際治療指引，旨在透過輸入客觀的抽血數據與臨床表徵，即時運算出臨床分期與建議治療策略，輔助臨床決策。

✨ 核心功能

本系統提供以下四大醫學評估工具的即時運算：

Child-Pugh Score & Class (肝功能分級)

根據總膽紅素、白蛋白、INR、腹水與肝腦病變程度，自動計算分數 (5-15) 並分類為 A, B, C 級。

ALBI Grade (白蛋白-膽紅素評分)

採用完全客觀的公式計算：(log10(Bili) × 0.66) + (Alb × -0.085)。

幫助更精準地評估早期/中期 HCC 患者的肝功能代償狀態。

MELD & MELD-Na Score (末期肝病模式)

針對末期肝病及需等待肝臟移植的患者，透過膽紅素、INR、肌酸酐與血清鈉離子精算 3 個月內死亡風險。

內建洗腎條件與數值防呆機制 (底限 1.0，肌酸酐上限 4.0)。

BCLC Staging (巴塞隆納肝癌分期 2022 版)

綜合患者體能狀況 (ECOG)、肝功能 (Child-Pugh) 與腫瘤特徵 (數量、尺寸、血管侵犯、肝外轉移)。

自動判定分期 (0, A, B, C, D) 並對應國際指引的標準治療建議。

🚀 系統特色與技術架構

純前端運算 (Client-Side Only)：無需後端伺服器，病患的檢驗數據完全留在使用者的瀏覽器中，無個資外洩風險。

單一檔案部署 (Single-File Architecture)：所有的 HTML、CSS 與 JavaScript 皆整合於單一檔案中，無需繁雜的編譯過程。只需雙擊檔案即可在任何現代瀏覽器執行。

PWA (漸進式網頁應用) 支援：

網頁內建動態產生的 manifest.json。

支援行動裝置「加入主畫面 (Add to Home Screen)」，提供宛如原生 App 般的全螢幕操作體驗。

響應式設計 (RWD)：完美適配手機、平板與桌上型電腦螢幕。

技術堆疊：

Vue.js 3 (CDN)：負責狀態管理與即時分數連動計算 (Reactivity)。

Tailwind CSS (CDN)：負責響應式 UI 排版與現代化美觀設計。

HTML5 / JavaScript (ES6)

📦 安裝與執行方式

方式一：本機直接執行

下載或複製本專案的 hcc-calculator-pwa.html 檔案。

在電腦或手機上使用任何現代瀏覽器（Chrome, Safari, Edge, Firefox）開啟該檔案即可使用。

方式二：靜態網頁託管 (如 GitHub Pages)

將 hcc-calculator-pwa.html 更名為 index.html。

將檔案上傳至 GitHub 儲存庫。

開啟該儲存庫的 GitHub Pages 服務。

使用者即可透過專屬網址隨時隨地存取。

📱 將其安裝為手機 App (PWA)

使用手機瀏覽器 (建議使用 Chrome 或 Safari) 開啟部署好的網頁網址。

點擊畫面上方的「安裝 APP」按鈕，或透過瀏覽器選單選擇「加到主畫面」。

日後即可直接從手機桌面點擊圖示開啟，享有獨立視窗的 App 體驗。
